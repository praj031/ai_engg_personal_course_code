What is uv:

- uv is a modern, extremely fast Python package and project manager written in Rust.
- It can handle much more than just virtual environments:
  - Python installation and version management
  - Virtual environments
  - Package installation
  - Dependency management
  - Lock files
  - Project management
- Instead of manually doing:
  ```bash
  python -m venv .venv
  pip install ...
  ```
  uv does all of this faster in one tool.

pyproject.toml is like pom.xml:

- Just like `pom.xml` manages Java project metadata, dependencies, and build in Maven, `pyproject.toml` does the same for Python.
- Example comparison:
  - Maven uses `<dependency>` blocks in `pom.xml`.
  - Python uses the `dependencies` list inside `pyproject.toml`.
- Adding a dependency:
  - Maven: add `<dependency>` manually.
  - Python with uv: run `uv add pydantic` and it updates `pyproject.toml` automatically.
- uv can also generate a `uv.lock` file to freeze exact versions, similar to `package-lock.json` in Node.js.

What is uv.lock file:

- `uv.lock` is a lock file generated by uv.
- It records the exact versions of all installed packages and their transitive dependencies.
- This ensures that everyone working on the project gets the exact same environment.
- It is similar to `package-lock.json` in Node.js or `yarn.lock` in Yarn.
- Benefits:
  - Reproducible installs across different machines.
  - Avoids unexpected updates or breaking changes from new releases.
  - Makes dependency resolution faster next time.
- You can update the lock file with:
  ```bash
  uv lock
  ```
- You can install dependencies from the lock file with:
  ```bash
  uv sync
  ```

What is Pydantic:

- Pydantic is a Python library for data validation and settings management.
- It uses Python type hints to validate that data has the correct shape.
- Benefits:
  - Automatic data validation.
  - Clear and useful error messages.
  - Easy conversion between Python objects and JSON.
  - Type safety with less manual checking.
  - Used by FastAPI, LangChain, and many AI/ML tools.
- Example:
  ```python
  from pydantic import BaseModel

  class User(BaseModel):
      name: str
      age: int
      email: str

  user = User(name="Pritish", age=25, email="pritish@example.com")
  ```
